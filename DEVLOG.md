# 1. Текущая цель
Развивать отдельный GitHub-форк Mooneva с оформлением cyclone, сохраняя его архитектуру расчётов.
# 2. Выполненные шаги
Создан https://github.com/etowhite/cyclone-mooneva (настоящий fork), локальная папка cyclone-mooneva, ветка cyclone/design. Слой cyclone.css, пять палитр, auto/light/dark, карточки с контуром, системная типографика и отдельная настройка оформления. Исходные services/logic не менялись. Typecheck и web build прошли, шесть контрактных тестов прошли. Проверены русские экраны настройки412x915, тёмная лаванда и светлый шалфей без горизонтального overflow. GPL и upstream-история сохранены.
# 3. Текущий статус и проблемы
Первый этап готовится к push/PR. Это веб-прототип, не готовый Android APK. Остались длинные подписи upstream, полная навигация/брендинг, Android identity/aliases/plugins, импорт nativecyclone, виджеты/биометрия. CI workflow добавлен, фактический запуск после push ещё не подтверждён. В public upstream отсутствовали tests, поэтому его suite нельзя считать пройденным.
# 4. Следующие шаги
Push ветки, создать PR и GitHub-задачи; проверить CI. Дальше последовательно делать мобильный редизайн и Android-адаптацию через отдельные PR.
